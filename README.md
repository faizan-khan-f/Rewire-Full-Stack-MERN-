Rewire, Reset & Rebounce

A full-stack Generative AI MERN application designed to help users break negative habit loops, reset dopamine baselines, and achieve long-term behavioral mastery through structured challenges and AI-driven coaching.

Key Features
Generative AI Clinical Coach (Spidey): Powered by the Google Gemini LLM, Spidey acts as a virtual psychologist. It dynamically generates highly personalized, scientifically-grounded daily routines based on custom user hurdles, complete with automated midnight task resets.

Progressive Challenge Tiers: 1-Week (Detox), 21-Day (Rewire), and 90-Day (Rebounce) protocols for structured habit transformation.

Custom Target Tracking & Notes: Persistent tracking for short and long-term goals (daily to 90-day), integrated with pop-up strategy note editors.

Sensory Gamification: Custom UX featuring Web Audio API sound engines (clicks and triumphant arpeggios) and canvas-confetti particle celebrations for milestone completions.

Secure Authentication: JWT-based session management, registration, and encrypted password recovery.

Tech Stack
Frontend: React, Vite, Tailwind CSS, Lucide Icons, Canvas Confetti

Backend: Node.js, Express.js, JWT, BcryptJS, Node-Cron

Generative AI: Google Gemini API (gemini-3.8-flash)

Database: MongoDB Atlas / Mongoose ODM
